# 뭉림고수

이뭉을 움직여 사방에서 돌진하는 햄찌를 피하는 오리지널 1인 생존 웹게임.
**한 번 닿으면 즉시 종료**되며, 버틴 시간이 기록입니다.

플레이: <https://obundh.github.io/hamzzi-worldcup/moonglim/>

- 디피진·저승사자·똔꾸리·다망해·공명·랫서쿠키가 가장자리에서 예고 후 돌진합니다.
- 조준은 예고 때 고정됩니다. 햄찌는 그 방향으로 직진합니다.
- 시간이 지나면 돌진 속도와 수가 늘고, 양쪽·세 갈래 패턴이 나옵니다.
- 발밑에 그려진 작은 원이 충돌 판정입니다. 피격 후 부활이나 추가 체력은 없습니다.
- 30초를 버티면 ‘뭉림고수’ 칭호를 얻습니다.
- 최고·최근 생존 시간과 도전 횟수는 현재 브라우저에 저장됩니다.

| 조작 | 방법 |
| --- | --- |
| 이동 | 방향키 / WASD |
| 마우스·터치 | 수련장 위를 누르며 드래그 또는 방향 버튼 |
| 시작·재도전 | Space / R 또는 버튼 |
| 일시정지·계속 | P / Escape 또는 버튼 |

다른 탭·창으로 이동하면 일시정지합니다. 소리 끄기와 움직임 줄이기를 지원합니다.
기록 초기화에는 확인이 필요하며 `hamzzi-moonglim-v1` 키만 갱신합니다.
저장이 차단되어도 같은 탭에서는 기록을 유지하고 안내를 표시합니다.
서버 순위나 부정행위 검증을 제공하지 않습니다.

## 실행과 구조

저장소 루트에서 `python -m http.server 5189` 실행 후
<http://127.0.0.1:5189/moonglim/>에 접속하세요.

- `engine.js`: 시드 난수, 원형 경계, 120Hz 고정 시뮬레이션, 연속 충돌 판정.
- `renderer.js`: 원형 대나무 수련장·햄찌 달리기·예고 표식·먼지·충돌 원.
- `game.js`: 키보드·터치·드래그, 시작·결과·일시정지, 로컬 기록.
- `audio.js`: 직접 합성한 바람·나무 타격음·종소리·부딪힘 효과음.
- 이미지: 이전 햄찌 게임에서 생성한 `../halloween/assets/npc-atlas.png`를 재사용합니다.
  이뭉은 6번 셀, 돌진 햄찌 여섯 명은 0–5번 셀입니다. 원작 게임의 그림을 복제하지 않았습니다.

외부 라이브러리·폰트·서버 API 없이 정적 호스팅으로 실행합니다.

## 검증

`node moonglim/tests/engine-check.cjs`

실제 브라우저에서 첫 피격 종료·기록 저장·재도전·일시정지·키보드/드래그·터치 조작을 확인했습니다.
모바일은 Chromium 터치 에뮬레이션으로 검증했으며 실제 기기의 성능·사람의 체감 난이도 검증은 포함하지 않습니다.
