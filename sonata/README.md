# 햄찌 소나타

Black Sonata의 숨은 이동과 정체 추리에서 착안한, 새 지도와 규칙의 1인 팬 게임입니다.
기존 월드컵의 16명 이름과 프로필을 그대로 사용하며, 네 가지 게임용 특징은 사건마다 배정합니다.

## 플레이

1. 난이도를 고르고 새 사건을 시작합니다. 같은 사건 번호는 같은 특징과 초기 배치를 만듭니다.
2. 한밤에 행동 두 번: 인접 장소로 이동하거나 지금 있는 곳을 수색합니다.
3. 행동을 모두 쓰면 그림자가 한 칸 이동합니다. 수색에 성공하면 단서 한 장을 얻고 그림자는 두 칸 도망갑니다. 이미 도망간 밤에는 밤 전환 때 추가로 움직이지 않습니다.
4. 네 가지 특징을 비교해 모든 단서를 만족하는 햄찌의 정체를 지목합니다. 지목은 한 번만 할 수 있습니다.

지목 전 행동 되돌리기, 후보·지도 메모, 추적 도움, 자동 저장, 사건 링크 공유를 지원합니다.
계정·서버·외부 API 없이 브라우저에서 진행됩니다. 저장이 차단되면 안내를 표시합니다.

`index.html`과 `engine.js`를 같은 폴더에 두고 정적 웹서버로 제공합니다.
게임의 비밀 정보는 브라우저 안에 있으며 경쟁용 부정행위 방지 기능은 없습니다.

모티브: [Black Sonata / Side Room Games](https://sideroomgames.com/product/black-sonata/).
원작 지도·카드·사건·문구를 사용하지 않습니다.
