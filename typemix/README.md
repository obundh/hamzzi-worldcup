# 랜덤 이상형

`https://obundh.github.io/hamzzi-worldcup/typemix/`

확인한 [원본 필터 영상](https://shorti.ai/en/v/instagram_DfoY6hjviiO)의 흰 세로선,
회색·노란 원과 내려오는 노란 공을 재현한 정적 웹 앱입니다.
Gender → Age → Height → Weight → Job → Nationality 순으로 자동 추첨합니다.
공은 화면 높이42.1875%에 고정되어 있고, 처음1초 뒤부터 줄이 일정하게
올라옵니다. 원본의 노드 간격350px·이동 속도90px/초를 비율로 적용하여
다음 결과까지 약3.89초가 걸립니다. 마지막 원에서 화면이 그대로 멈춥니다.
사람이 있던 화면에는 기존 게임에서 생성한 햄찌 에셋을 표시하며,
다시 시작할 때 디피진·저승사자·똔꾸리·다망해·공명·랫서쿠키·이뭉 중 배경이 바뀝니다.

최종 결과에는 여섯 조건을 모두 반영한 한국어 이미지 생성 프롬프트가 하나 나옵니다.
복사해서 GPT·Gemini 등에 직접 붙여넣습니다. 앱에서 AI API를 호출하지 않습니다.
키보드 Tab/Enter, 모바일 터치, 일시정지/계속, 다시 뽑기를 지원합니다.
다른 탭으로 이동하면 추첨을 정지하며, 다시 계속하기를 눌러야 진행합니다.

카메라는 켜기 버튼을 누를 때만 요청하며 오디오는 요청하지 않습니다.
영상은 현재 기기의 배경으로만 표시하며 전송·저장하지 않습니다.
카메라 없이도 모든 기능을 쓸 수 있습니다. 기존 결과는 브라우저
localStorage의 `hamzzi-typemix-v1`에만 저장합니다.

원본 영상은 직업·국적 결과 전에 초기화되므로 전체 값 목록과 확률은 확인되지
않았습니다. 구현은 성별 2종, 나이16~90, 키100~230cm, 몸무게35~300kg,
직업·국적 각20종을 독립적으로 균등 추첨합니다. 현실적인 체형으로 제한하지 않습니다.
원본 제작자의 영상·얼굴·음원은 포함하지 않습니다. 햄찌 배경은 기존
`../halloween/assets/npc-atlas.png`를 재사용합니다.

확인 명령: `node typemix/tests/model-check.cjs`
로컬 실행: 저장소 루트에서 `python -m http.server 5192` 실행 후
`http://localhost:5192/typemix/`에 접속합니다.
