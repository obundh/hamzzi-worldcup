# 햄찌 월드컵 🐹

첨부 명단의 15명에 **조용한닝겐**을 추가한 16강 월드컵입니다.

- 대진 무작위 배정, 16강 → 8강 → 4강 → 결승 → 우승
- 제목 입력칸에서 월드컵 주제 지정: 대결, 결과, 공유 링크에 같은 제목 사용
- 이전 선택 되돌리기, 진행 기록 자동 저장, 새 대진으로 다시 하기
- 우승 결과 공유 링크, 전체 대결 기록
- 모바일·터치·키보드 지원, 외부 서비스·라이브러리 없이 실행

`index.html`을 브라우저에서 열거나 GitHub Pages 주소에 접속하세요.
프로필은 제공된 이미지에서 CSS로 해당 위치를 표시합니다. 조용한닝겐은 별도 이미지가 없어 🤫 아이콘을 사용합니다.

진행 기록은 현재 브라우저의 localStorage에만 보관됩니다. 저장이 차단되면 안내를 표시합니다.
서버, 로그인, 방문자 공통 순위 또는 투표 집계는 사용하지 않습니다.
공유 링크는 해당 참가자가 우승했다는 결과 화면을 표시하며 실제 투표 증명은 아닙니다.
