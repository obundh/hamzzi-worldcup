# 문을 연 햄찌

이뭉이 여섯 햄찌 사이의 소환자를 밝혀내는 오리지널 1인 공포 추리 웹게임.
할로윈 파티가 끝난 뒤, 썩은 호박 가면을 쓴 귀신이 미로를 배회합니다.

플레이: <https://obundh.github.io/hamzzi-worldcup/halloween/>

## 플레이

1. 미로를 탐색하며 여섯 햄찌를 만나고 바닥의 소환 흔적 3개를 찾습니다.
2. 수첩의 참석자 기록에서 양초 색·초대장 리본·문양을 대조합니다.
3. 세 흔적을 모두 만족하는 한 명을 고릅니다. 여섯 명의 조합은 서로 다릅니다.
4. 처음 들어온 출입문으로 돌아가 그 이름을 새기면 탈출합니다.

귀신은 벽에 막히는 시야와 달리는 소리에 반응합니다. 모퉁이를 돌아 시야를 끊고
옷장에 숨을 수 있습니다. 바로 앞에서 들킨 상태에서는 숨을 수 없습니다.
귀신에게 한 번 잡히면 흔적을 유지한 채 입구로 돌아오며, 두 번째에는 수사가 끝납니다.
지목 기회는 한 번입니다. 잘못 지목해도 수사가 끝납니다.

일반/쉬운 모드, 손전등·체력·건전지, 탐색 지도, 자동 저장·재개, 확인 후 기록 초기화가 있습니다.
수첩·대화·메뉴를 읽거나 다른 탭으로 이동하면 게임 시간이 멈춥니다.
소리 끄기와 놀람 연출 줄이기를 지원합니다.

| 조작 | 키보드 | 휴대폰·터치 태블릿 |
| --- | --- | --- |
| 이동 | WASD / 방향키 | 방향 버튼 |
| 달리기 | Shift 누르기 | 달리기 누르기 |
| 조사·대화 | E | 조사 / 대화 |
| 옷장 숨기·나오기 | Space | 숨기 / 나오기 |
| 손전등 | F | 빛 |
| 수첩 / 지도 / 정지 | J / M / Escape | 상단 메뉴 버튼 |

## 에셋과 구조

- `assets/ghost-atlas.png`: 대기·배회·추격·공격, 각 4장 = 16프레임.
- `assets/scare-atlas.png`: 갑툭튀 4프레임. 총 귀신 이미지 20프레임.
- `assets/npc-atlas.png`: 디피진·저승사자·똔꾸리·다망해·공명·랫서쿠키·이뭉.
- `assets/title-scene.png`: 생성형 할로윈 미로 타이틀 장면.
- 프롬프트·참조·실제 이미지 규격은 [ASSETS.md](ASSETS.md)와 `assets/manifest.json`에 있습니다.
- `engine.js`: 시드 미로, 추격 AI, 단서·지목, 저장 검증.
- `renderer.js` / `audio.js`: Canvas 2D와 오리지널 WebAudio 효과음.
- `game.js`: 키보드·터치, 수첩·대화·메뉴, 로컬 저장.

외부 런타임 라이브러리·폰트·로그인·서버 API를 사용하지 않습니다.
진행은 브라우저의 `hamzzi-halloween-v1`, 설정은 `hamzzi-halloween-settings-v1`에 저장합니다.
초기화는 이 게임의 진행 키만 지우며 다른 게임이나 설정을 지우지 않습니다.
게임 상태와 정답은 브라우저에서 계산하므로 경쟁 기록 검증용 게임은 아닙니다.

## 로컬 실행

저장소 루트에서 `python -m http.server 5188` 실행 후
<http://127.0.0.1:5188/halloween/>에 접속하세요. 정적 서버로 배포할 수 있습니다.

엔진 검사는 `node halloween/tests/engine-check.cjs`로 실행합니다.

검증 범위: 600개 시드 사건의 연결성·단서 유일성·이동 충돌·포획·은신·저장 검증,
읽기 전용 독립 검사에서 귀신을 활성화한 이동 시뮬레이션 120건,
Chromium의 PC·모바일·터치 태블릿 UI·저장·결말 확인.
시뮬레이션과 브라우저 터치 에뮬레이션이며 실제 기기의 성능이나 사람의 공포감·난이도 평가를 뜻하지 않습니다.
